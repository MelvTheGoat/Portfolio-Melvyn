Premier League Match Predictor

A self-retraining match predictor that publishes three-way probabilities and a scoreline for every fixture, keeps every prediction it has ever made on the record, and retrains after each gameweek. Deployed and live.

Open live demo → View on GitHub →

01The problem

A league table describes what happened; it does not describe the situation a match is played in, and the situation often decides it. A club four days after a European tie fields a different side. A club that changed manager last month is not the team that finished last season. The tempting fix is a checklist — if new manager, add 5% — hand-tuned per fixture. This project refuses that entirely.

02The result

Headline number

Walk-forward backtest over 2023-24, 2024-25 and 2025-26 from gameweek 4 onward (1,050 matches): 52.1% outcome accuracy against 43.2% for always backing the home side, log loss 0.9948 against 1.0061 for a tuned Elo-only baseline, 8.2% of exact scorelines, and goals MAE of 0.93 per side. Live on Vercel, republished by a scheduled retrain.

03Architecture

openfootball ingest → 204-column point-in-time feature table (one chronological pass) → LightGBM + multinomial logistic blend (outcome) · Dixon-Coles bivariate Poisson (scoreline) → predict next gameweek → store as an immutable run → export 1.4MB serving DB → Vercel

04The hardest decision

Every contextual signal becomes a feature, never an adjustment

Congestion, manager tenure, availability, squad quality and table pressure all go into the feature table as numbers and are left for the model to weigh. Nothing anywhere applies a hand-tuned bump to a prediction. Where a signal resists measurement the answer is a better proxy, not a rule: “new manager bounce” becomes days since the appointment, matches played under the new manager, and the points-per-game difference either side of the change. If those matter the model finds them; if not, it ignores them. The same discipline drives the cross-division Elo — rated over the Premier League, the Championship, League One and the cups on one scale — which is the only thing that stops three promoted clubs a season starting as blanks.

05What the results actually showed

Measured, not assumed

Calibration is the number that matters here, because the site publishes probabilities rather than picks: when the model says 65% it happens about 65% of the time, across every band from 0.16 to 0.74. That came from the linear half of the ensemble and from early-stopping the boosting rounds — a fixed 400 rounds produced visible over-confidence in the 0.5–0.8 band and cost about 0.03 nats. Two things are reported rather than smoothed over: draws are almost never the argmax, so they are expressed as probability mass (typically 25–30%) instead of being forced into picks; and per-season accuracy ranges 57.1% / 52.0% / 47.1%, mostly a property of the seasons — 2025-26 had eleven managerial changes — not of the model.

06What's next

Automate team news. The injury and suspension file ships empty, and a club with no row is treated as unknown rather than fully fit — so the feature removes itself instead of biasing the model. Filling it reliably is the single largest gain left on the table.
